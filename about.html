OUR PURPOSE

Why CollegeWise was built

MISSION

🎯 Demystifying Admissions

Choosing a higher education institution is one of the most consequential decisions a student makes. Yet, aspirants often struggle with conflicting brochures, unverified ranking lists, and aggressive marketing. CollegeWise aggregates verified data across rankings, fees, cut-offs, and placements into an honest, easy-to-use platform so students can evaluate their options objectively.

VISION

✨ Personalized Career Guidance

No two students are identical. An institution that is ideal for a research aspirant may not suit someone prioritizing rapid corporate placements or budget-friendly education. Our vision is to provide every student with an individualized roadmap based on their unique 12th grades, entrance percentiles, career goals, and financial preferences.

SYSTEM DESIGN

Full-Stack Software Architecture

CollegeWise is designed as a secure, high-performance, modular full-stack application following industry standard Software Requirements Specifications (SRS):

🖥️ Frontend Client

  • Modern semantic HTML5 & Responsive CSS3
  • Dynamic DOM rendering with Vanilla JS
  • Client-side state & responsive touch UX
  • Role-aware UI (Student & Administrator views)
  • Seamless REST API client integration

⚡ Backend REST API

  • Node.js & Express application server
  • Stateless JWT authentication & bcrypt hashing
  • Role-based access control (RBAC) middleware
  • Weighted algorithmic recommendation pipeline
  • Comprehensive CRUD endpoints for colleges

🗄️ Persistence Layer

  • Relational schema with normalized tables
  • Users, Colleges, Favourites, & Activity logs
  • Pre-seeded with NIRF rankings & verified metrics
  • ACID transaction support with zero external setup
  • Instant search and parameterized SQL filtering
